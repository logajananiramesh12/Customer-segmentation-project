# Customer Segmentation using K-Means Clustering

## Project Overview

This project segments customers based on Age, Annual Income, and Spending Score using K-Means Clustering.

## Tools Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Feature Selection
4. Data Scaling using StandardScaler
5. Elbow Method
6. K-Means Clustering
7. PCA Visualization
8. Business Insights

## Key Findings

* VIP Customers
* Young High Spenders
* Mature Moderate Spenders
* Average Customers
* High Income Low Spenders

## Outcome

The project helps businesses understand customer behavior and create targeted marketing strategies.
